4 · Analysis engine (implement exactly per spec §5)

Pure Dart, no Flutter imports. Lives at lib/features/analysis/domain/use_cases/behavior_analysis_engine.dart. Takes logs + current schedule, returns AnalysisResult. Deterministic order — check in this sequence:

  1. baseline fewer than 3 days logged → "Keep observing"
  2. goalReached last 7 days all ≥ goal → mark complete
  3. extinctionRisk last 3 days with reinforcementGiven == false
  4. plateauDetected last 5 days within ±1 of each other, avg < goal − 1, schedule active ≥ 7d
  5. scheduleUpgrade CRF → FR-2 after 5+ consecutive days at goal with stddev < 1.5; FR → VR after 7 days at goal on FR
  6. onTrack default fallback

Copy (verbatim, UI-ready)

StatusHeadlineExplanation
baselineKeep observing — X of 3 days loggedA few baseline days help us understand where Maya is now, before we suggest a plan.
onTrackNice progress — on track toward goalKeep giving a sticker every single time — consistency is what makes a new habit stick.
scheduleUpgradeGreat streak! Time to mix up the rewardsRewarding every 2 times (instead of every time) makes the habit stronger and more lasting.
plateauDetectedProgress has flattened — let's adjustA fresh reward or a slightly easier goal can spark new motivation.
extinctionRiskRewards have slipped — let's get back on trackBehaviors weaken quickly when rewards stop. Hand out a sticker today.
goalReachedGoal reached — 21 days of steady tidy-ups 🎉The habit is established. Move to surprise rewards to keep it going long-term.

6 · Responsive — mobile vs web

Flutter web gets the same widget tree with a LayoutBuilder at the screen root. Below 800px width → use the mobile screens as-is. At ≥ 800px → compose the WebScreen layout (sidebar · main · right rail). The main column swaps in the full-width ProgressChart; the right rail hosts the SuggestionCard and a TimelineCard.

LayoutBuilder(builder: (ctx, c) {
  final wide = c.maxWidth >= 800;
  return wide
    ? DashboardLayout(subjectId: id)   // sidebar + main + rail
    : SubjectDetailScreen(subjectId: id);
});

8 · Seed data for the preview states

Ship a dev-only SeedService that loads on first launch when kDebugMode. Creates subject Maya (6, parent) and target "Tidying up toys after play" (baseline 1, goal 4, increasing). Generates 21 days of logs per state in lib/features/analysis/data/fixtures.dart.

9 · Definition of done

  • Happy path works end-to-end on mobile AND web without layout breakage.
  • BehaviorAnalysisEngine.run() returns correct AnalysisStatus for each of the 6 fixture histories in the preview.
  • Progress chart matches reference: occurrence line, green points ≥ goal / amber points below, dashed goal line, schedule-change marker, today-pulse.
  • All copy comes from §4 of this doc — no psych jargon in the UI.
  • Hive boxes persist across app restart.

10 · Out of scope (spec §8)

No auth, no backend, no push, no cloud sync, no punishment-based interventions, no media attachments to logs.
